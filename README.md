# SRA Jewellers — Frontend

A premium jewellery e-commerce **frontend only** built with Next.js (App Router), TypeScript, and Tailwind CSS. No backend, database, payment gateway, or real APIs are implemented — everything runs on mock data and browser localStorage, structured so a real backend can be wired in later.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

This repository is a portfolio/demo project. It contains no real customer records or production credentials. Copy `.env.local.example` to `.env.local` only when configuring local services, and never commit `.env.local`.

To build for production:

```bash
npm run build
npm run start
```

## What's inside

- **50 mock products** across 8 categories in `src/data/products.ts` (auto-generated by `scripts/generate-products.mjs` — re-run it if you want to regenerate with different names/prices).
- **Pages**: Home, Shop, Category, Product Details, Search, Cart, Checkout, Order Success, Order Tracking, Custom Design Request, About, Contact, Collections/Offers, Wishlist.
- **State**: Cart, wishlist, recently viewed, custom design requests, and client-generated orders persist to `localStorage` via Zustand (`src/lib/store`).
- **Gold Rate widget**: floating pill (bottom-left) + modal, mock values in `src/data/goldRates.ts`.
- **Custom Design flow**: drag-and-drop upload (JPG/PNG/WEBP/PDF), generates a mock `SDR-2026-XXXX` request ID.
- **Order Tracking**: try sample IDs `SRA-2026-00124`, `SRA-2026-00098`, `SRA-2026-00045`, or any order placed through Checkout in this browser.
- Every place a real backend would be needed has a `// TODO(backend): ...` comment pointing to the API call it should become.

## Replacing mock images

Product/category/collection images currently come from `loremflickr.com` (keyword-matched placeholders) so the catalogue looks populated out of the box. Swap the `image` / `gallery` fields in `src/data/*.ts` for real SRA Jewellers photography — components already read from these fields, no UI changes needed.
